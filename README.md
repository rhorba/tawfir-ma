# Tawfir.ma — Digitized Rotating Savings (ROSCA)

Morocco's traditional 'daret' rotating savings groups have ~4M participants operating entirely on paper and trust.

## Problem
No digital infrastructure for group savings. Defaults and disputes are common. Members can't build savings history.

## Solution
Digitize the daret: group creation, contribution schedules, automatic payout rotation, dispute resolution, and savings history that feeds into Kasb credit scores.

## Stack
Next.js 15, TypeScript, PostgreSQL 16 + RLS, Auth.js v5 (phone OTP), Drizzle ORM, pg-boss, CMI mobile money, Tailwind v4

## Completes
Kasb (informal credit scoring → formal savings product)

## Key Roles
Group Organizer | Member | Admin
